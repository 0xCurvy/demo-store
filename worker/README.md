# Worker

The Cloudflare Workers build of the shop goes here: the same order flow as `server/`, with Hono in place of
Express, D1 in place of the JSON file, R2 in place of the `wallpapers/` folder and a cron trigger in place of the
in-process reconciler. `wrangler.toml` is generated by Terraform from `infra/`; see `infra/README.md`.
